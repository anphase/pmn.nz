# Accessibility checks

`npm run test:e2e` builds the site (`JEKYLL_ENV=production bundle exec jekyll build` into a temp
directory, or serves `SITE_DIR` if set), serves it on a free local port and runs Playwright
(Chromium, 4 workers) from `tests/e2e/`:

- axe-core (`wcag2a`, `wcag2aa`, `best-practice`) on home, blog index, the newest post, books,
  the first book page, projects, fails and 404, at 375px and 1280px, in the light and dark themes. Any violation fails.
- keyboard: the skip link is first in tab order, appears and moves focus to `#main-content`; every
  sidebar link is reachable with a visible focus ring.
- image modal (`assets/js/image-modal.js`) on the newest post: opens by keyboard, focus moves to
  Close, Escape or Close closes it, focus returns to the image link.

First run: `npm install && npx playwright install chromium`.

## Fixed

- Content links used hyde's `#75b5aa` (2.3:1); now the teal token (`custom.css`).
- Inline `code` used `#bf616a` on `#f9f9f9` (3.9:1); now the `--code-ink` token, AA in both themes.
- Sidebar content sat outside any landmark; the sidebar is now a `<header>`.
- `<main>` is `tabindex="-1"` so the skip link moves focus, not only scroll position.

## Exceptions

None. Both themes are tested: the axe spec emulates the light and dark colour schemes.
